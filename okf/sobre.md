# HookPulse

Get an ingest URL. Your cron, Stripe or n8n pings it on schedule. If pings stop, we record a miss. Not website uptime monitoring.

## O que faz

* Ingest URL for cron and webhooks
* Miss detection when pings stop
* Email alert on silence
* Public status page per owner, as JSON and RSS
* Agent-first HTTP API with x402 billing
* MCP server for agents

## Preço

* Free: ten monitors, intervals from 90 s, one e-mail alert, unlimited pings, status page; sign in and confirm your email for 90 days of full access: grátis
* Extra monitor beyond the free ten: 0.10 USD
* E-mail alert beyond the first destination: 0.10 USD
* Interval under 90 s: 0.05 USD
